A file hash is a unique, fixed-length string of alphanumeric characters generated by running a file's binary data through a mathematical algorithm. Hashing transforms data of any size into a unique, fixed-length string of characters.

## How It Works:
- Every file acts as input data that produces a specific hash value (or digest).

- Changing even a single bit or character in the file completely changes the resulting hash. 

- Hashing is irreversible. You cannot recreate the original file just by looking at its hash. 

- No matter how large or small the file is (a tiny text file or a 4GB ISO), the output hash has a fixed length depending on the algorithm.

## Common Hashing Algorithms

-   **SHA-256:** The current industry standard for strong security and collision resistance (64 characters). 

-   **SHA-1:** An older algorithm (40 characters) that is largely deprecated due to security vulnerabilities.

-   **MD5:** A fast, legacy algorithm (32 characters) that is insecure and vulnerable to collisions, used mostly for basic checksums rather than security. 

## Common Uses

-   **File Integrity Verification:** Checking whether a downloaded file (like a software update or OS image) is complete and uncorrupted by comparing its hash to the publisher's official hash. 

-   **Malware Detection:** Security tools and analysts use database lookups of known malicious file hashes (via platforms like VirusTotal) to spot threats instantly without opening the file.

-   **Deduplication & Forensics:** Tracking digital evidence or spotting duplicate files across storage systems quickly. 

-   **Password Security.** Websites never store your actual password in plain text. Instead, they run it through a slow hashing algorithm with a random "salt" so hackers cannot reverse-engineer your credentials if a database leaks.

-   **File Integrity and Checksums.** Software developers publish a cryptographic hash alongside downloadable files. Your device can compute the hash of the downloaded file to verify it was not corrupted or tampered with during transit.

-   **Data Structures and Databases.** Software engineers rely on hash tables every day to index and retrieve data in near-instant time

-   **Digital Signatures and HTTPS.** Secure web browsing and software certificates rely on hashes to prove that messages and code come from a verified, authentic sender.

-   **Blockchains and Cryptocurrencies.** Networks like Bitcoin use hashing to link blocks of transactions together permanently and verify proof-of-work.


## Generate a File Hash (Windows OS)

-   **Windows (PowerShell):** Run `Get-FileHash -Path "C:\path\to\file.iso" -Algorithm SHA256`.

-   **Windows (Command Prompt):** Run `CertUtil -hashfile "C:\path\to\file.iso" SHA256`.

To generate a hex digest in Python, you pass byte-encoded data into a hash algorithm and call .hexdigest() (cite 1)

Using Python 3.11 or newer, use the built-in hashlib.file_digest() helper. It is highly optimized, handles chunking automatically under the hood, and is safe for files of any size. 


Pitfalls to Avoid:
-   **Always use `"rb"` mode**: Files must be opened in binary read mode (`"rb"`). Opening a file in standard text mode (`"r"`) will cause Python to decode characters, altering the raw bytes and corrupting the resulting hash.    

-   **Never use the built-in `hash()` function**: The built-in `hash()` function is intended strictly for internal data structures like dictionaries. It randomizes its seed on every Python run for security, meaning it will return a completely different value every time your script runs.
